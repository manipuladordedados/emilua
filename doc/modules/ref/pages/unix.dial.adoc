== Synopsis

[source,lua]
----
local unix = require "unix"
local fs = require "filesystem"

unix.stream.dial()
unix.seqpacket.dial()
unix.datagram.dial()

function(ep: string) -> socket
----

== Description

1. Creates a socket.
2. Connects the created socket to `ep`.
3. Returns the connected socket.

NOTE: If `ep` starts with `@` then it's assumed to represent an abstract UNIX
socket.

Current fiber is suspended until operation finishes.
