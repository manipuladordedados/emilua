== Synopsis

[source,lua]
----
local unix = require "unix"
local fs = require "filesystem"

unix.stream.dial()
unix.seqpacket.dial()
unix.datagram.dial()

function(p: string|fs.path) -> socket
----

== Description

1. Creates a socket.
2. Connects the created socket to `p`.
3. Returns the connected socket.

NOTE: If `p` is a string and starts with `@` then it's assumed to represent an
abstract UNIX socket.

Current fiber is suspended until operation finishes.
